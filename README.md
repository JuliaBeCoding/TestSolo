# TestSolo

För betyg G:

Länk till Github-repository (publikt) med ett vite-projekt med en kalkylator som kan utföra de fyra räknesätten, samt ett test av varje räknesätt (vitetest ska användas)

För betyg VG:

Dessutom en frontendapp som utför följande: inloggning mot mitt REST-API (jwt-varianten) och med möjlighet att registrera nya filmer (alla fält ska finnas med förutom id), samt kunna visa en lista med alla filmer (alla fält ska visas förutom id).
